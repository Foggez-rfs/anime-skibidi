# anime-skibidi
Anime vs Skibidi — пошаговая PvP-игра, где аниме-персонажи (Зоро, Наруто, Гоку, Айзен) сражаются против вселенной Скибиди Туалет (Камера Мен, ТВ Мен, Титан Сирена). 34 персонажа, 10 редкостей, кейсы с шансами, улучшения за монеты, крафт (золотая/алмазная машина), ранговая система и бои с друзьями или ботом.
